# ドット花火 (dot_hanabi)

ドット絵で花火のデザインを描くと、夜空にその花火が打ちあがる Web アプリです。
素の HTML / CSS / JavaScript (Canvas) のみで作られており、ビルド不要で動きます。

## 遊び方

1. 「花火をデザインする」からエディタを開く
2. 5×5 / 15×15 / 30×30 からタイルサイズを選び、色を塗って花火の爆発デザインを描く
   (「点対称に描く」を ON にすると、花火らしい対称形が描きやすくなります)
3. 「プレビュー」で爆発演出を確認し、「保存する」でブラウザに保存
4. 夜空のページに戻ると、保存した花火がランダムなタイミング・位置で打ちあがります
   (夜空をクリックすると、その場所にランダムな花火を打ち上げられます)

保存された花火のうち、「夜空に打ち上げる」がONのものだけが夜空に登場します。
チェックを外すと、削除せずにその花火を夜空から除外できます。

## 花火を人に共有する

各花火カードの「共有コード」ボタンを押すと、そのデザインを表す短いテキストコードが
表示されます。これをコピーして相手に渡し、相手がエディタの「共有コードから読み込む」
ボタンにペーストすると、同じデザインが相手のギャラリーに追加されます。
サーバーを介さず、コードの文字列だけでデザイン一式(サイズ・色・ドット配置)を
やり取りする仕組みです。

## ローカルでの動かし方

このアプリは ES モジュール (`<script type="module">`) を使っているため、
`index.html` を直接ブラウザで開く (`file://`) と動作しないことがあります。
簡易 HTTP サーバー経由で開いてください。

```bash
# Python がある場合
python -m http.server 8000

# Node.js がある場合
npx serve .
```

その後、ブラウザで `http://localhost:8000` を開いてください。

## データの保存範囲について

現状、花火のデザインは各ブラウザの `localStorage` にのみ保存され、他の訪問者とは共有されません。
将来的にサーバー/DB (Firebase, Supabase など) を導入し、みんなが打ち上げた花火をリアルタイムで
共有できるようにする計画です。

## ディレクトリ構成

```
index.html       夜空ページ
editor.html      ドット絵エディタ + 保存済み花火ギャラリー
css/style.css    スタイル
js/storage.js    localStorage への花火デザインの保存・読み込み
js/pixel-grid.js パレット定義・グリッド描画ユーティリティ
js/firework.js   花火の打ち上げ・爆発アニメーション本体
js/sky.js        夜空ページの制御ロジック
js/editor.js     エディタページの制御ロジック
js/share-code.js 花火デザイン ⇔ 共有コードの変換
```
